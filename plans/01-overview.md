## Apa itu Retino?

Retino adalah aplikasi web untuk membantu user **mengelola habit harian dan task** secara lebih terstruktur, dengan bantuan insight otomatis yang terasa personal.

Berbeda dari to-do list biasa, Retino punya:
- Pemisahan antara **Habit** (kebiasaan rutin) dan **Task** (tugas dengan deadline)
- **AI rule-based** yang membantu user tanpa perlu input manual berlebihan
- **Insight harian** yang berubah sesuai kondisi user hari itu

---

## Tujuan Aplikasi

| Tujuan | Penjelasan |
|---|---|
| Kelola habit harian | User bisa tambah, edit, hapus, dan tandai habit selesai |
| Kelola task & deadline | User bisa atur task dengan prioritas dan deadline |
| Insight otomatis | App "ngerti" kondisi user dan kasih saran/insight |
| Visualisasi progress | User bisa lihat perkembangan habit & task secara visual |

---

## Target Pengguna

Orang yang ingin lebih produktif dan konsisten dalam keseharian — pelajar, mahasiswa, pekerja, siapapun yang butuh sistem untuk melacak kebiasaan dan tugas mereka.

---

## Perbedaan Habit vs Task

| | Habit | Task |
|---|---|---|
| **Definisi** | Kebiasaan rutin yang dilakukan setiap hari | Tugas spesifik dengan deadline |
| **Contoh** | Lari pagi, baca buku, meditasi | Kumpul laporan, bayar tagihan |
| **Deadline** | Tidak ada, dilakukan setiap hari | Ada deadline spesifik |
| **Prioritas** | Tidak ada | Ada (High/Medium/Low) |
| **Tracking** | Streak harian | Status selesai/belum |

---

## 4 Halaman Utama

```
1. Dashboard    → Ringkasan harian + insight
2. My Habits    → Kelola semua habit
3. My Tasks     → Kelola semua task
4. Statistics   → Visualisasi progress
```

---

## Nilai Utama Aplikasi

- **Simple** — tidak overwhelming, fokus pada yang penting
- **Smart** — AI bantu user tanpa perlu input manual berlebihan
- **Personal** — insight berubah sesuai kondisi user hari itu
- **Gratis** — tidak bergantung pada API berbayar
